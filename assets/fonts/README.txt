Minecraft Rus font

The site is configured to load the exact font from:
assets/fonts/minecraft-rus.ttf

Download the Minecraft Rus font from the source provided by the site owner:
https://fonts-online.ru/fonts/minecraft-rus
Then place the TTF file in this folder and name it minecraft-rus.ttf.
The download page currently presents an image CAPTCHA, so the font binary is intentionally not redistributed in this archive.
All site text already uses the MinecraftRus font family and will switch automatically once the TTF file is added. Until then, a monospace fallback is used.
