# Aves3D — GitHub Pages

## Структура
- `index.html` — главная страница и услуги
- `socials.html` — отдельная страница соцсетей
- `styles.css` — адаптивный дизайн, светлая и тёмная темы
- `script.js` — меню, переключатель темы, калькулятор и формирование заказа
- `assets/` — изображения проекта
- `assets/icons/` — пользовательские иконки из архива

## Что обновлено
- Добавлен переключатель светлой/тёмной темы. Выбор сохраняется в `localStorage`.
- Добавлена кнопка YouTube в первом экране.
- В форму заказа добавлен обязательный контакт: Discord или Email. Контакт попадает в сформированное сообщение.
- FAQ использует анимированный SVG-подобный CSS-chevron.
- Добавлен адаптивный блок отзывов.
- Иконки YouTube, Twitch, Discord, Telegram и стрелки взяты из пользовательского архива.

## Перед публикацией
1. В `assets/fonts/` положите файл шрифта `minecraft-rus.ttf`, если он у вас есть. CSS уже ссылается на `assets/fonts/minecraft-rus.ttf`.
2. Замените демонстрационные отзывы в `index.html` реальными отзывами клиентов и получите согласие на их публикацию.
3. Проверьте контактные ссылки и тексты услуг.
4. Загрузите содержимое этой папки в корень GitHub-репозитория и включите GitHub Pages в настройках репозитория.

## Важно о заказах
Форма формирует заказ, копирует его вместе с контактными данными и открывает Discord-сервер. Она не отправляет данные на сервер автоматически. Для автоматической доставки заявок потребуется backend или внешний сервис обработки форм.
