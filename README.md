# Aves3D — Студия 3D-рендеров по Minecraft

Официальный лендинг студии 3D-визуализации, созданный для быстрого и удобного заказа уникальных аватарок, полноценных рендеров персонажей и обложек (превью) для YouTube в стиле Minecraft.

**Автор проекта:** [@Aves_gree](https://youtube.com)

## Для чего нужен этот сайт

Сайт работает как полноценная витрина услуг и площадка для приёма заявок. Он решает сразу две задачи:
1. **Для клиентов:** позволяет быстро ознакомиться с примерами работ, выбрать подходящий тариф, рассчитать стоимость и оформить заказ без долгих переписок в личных сообщениях.
2. **Для автора:** автоматизирует сбор первичной информации от заказчика (никнейм, скин, желаемый тариф, дополнительные пожелания и контакты для связи).

## Как всё устроено и работает

Проект представляет собой лёгкий, быстрый и адаптивный одностраничный сайт (лендинг), написанный на чистом **HTML5, CSS3 и JavaScript** без использования тяжёлых сторонних фреймворков.

### Основные разделы и функции:
* **Главный экран (Hero Section):** презентация студии, быстрый переход к каталогу услуг и прямая ссылка на YouTube-канал автора для просмотра примеров в динамике.
* **Портфолио и тарифы:** разделение услуг на понятные категории (*Простая/Супер Аватарка*, *Простой/Супер Рендер*, *Рендер Превью*) с прозрачным прайсом, доступным даже начинающим блогерам.
* **Конструктор заказа (Собери свой заказ):** интерактивная форма, где клиент выбирает нужную услугу, указывает детали (позу, эмоции, наличие текста или фона) и оставляет свои контакты (Discord или Email) для обратной связи.
* **Переключатель тем (Light / Dark Mode):** встроенная смена светлого и тёмного оформления интерфейса с автоматическим сохранением выбора пользователя в браузере (`localStorage`).
* **Блок FAQ (Частые вопросы):** интерактивный аккордеон с плавной анимацией, отвечающий на популярные вопросы о сроках выполнения, оплате и правках.
* **Страница соцсетей (`socials.html`):** отдельный хаб со всеми актуальными ссылками для связи с автором и слежения за обновлениями.

```text

    └── *.png           # Примеры готовых рендеров, аватарок и логотип студии
```


## Как запустить сайт локально или задеплоить

Поскольку сайт состоит из статических файлов, для его работы не требуется сложный бэкенд или установка зависимостей:

1. **Локальный запуск:** просто скачайте репозиторий и откройте файл `index.html` в любом современном браузере (Chrome, Edge, Firefox, Яндекс Браузер).
2. **Публикация в интернет (GitHub Pages):**
   * Загрузите файлы проекта в публичный репозиторий на GitHub.
   * Перейдите в **Settings** (Настройки) -> **Pages**.
   * В пункте **Branch** выберите ветку `main` (папку `/root`) и нажмите **Save**.
   * Через пару минут сайт станет доступен по вашей персональной ссылке GitHub Pages.
